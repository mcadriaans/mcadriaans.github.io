ℹ️ About This Project

This project demonstrates modern analytics engineering best practices by building a scalable, tested, and documented data warehouse pipeline.

Key Technical Highlights:

  • Data Warehousing: Configured Snowflake as the central cloud data platform.
  • Data Transformation (dbt): Architected a multi-layer pipeline (Bronze/Staging, Silver/Cleansed, Gold/Marts).
  • Slowly Changing Dimensions (SCDs): Implemented dbt snapshots to track historical state changes in bookings.
  • Incremental Loading: Built incremental models (e.g., silver_hosts, silver_listings) to efficiently process new data using delete+insert strategies.
  • Data Quality & Testing: Enforced data integrity using primary key constraints, `not_null` checks, and custom dbt expectations (e.g., ensuring no overlapping active SCD records).

The final Gold layer exposes star-schema fact and dimension tables, powering the interactive dashboard to analyze host performance, cancellation rates, and booking trends.
