ℹ️ About the Case Study

This analysis explores the relationship between a diamond's characteristics (such as carat weight, cut quality, color, and clarity) and its overall price.

The project covers the end-to-end machine learning lifecycle:

  • Data Cleaning & EDA: Handling missing values, outliers, and uncovering correlations.
  • Feature Engineering: Encoding categorical variables and scaling numerical data.
  • Model Training: Evaluating various regression algorithms to find the most accurate predictor.
  • Performance Evaluation: Using metrics like RMSE and R² to measure model success.

All raw data, files, and source code are available in the GitHub repository via the links above.
