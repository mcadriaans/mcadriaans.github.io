ℹ️ About the Case Study

This project uses machine learning regression to predict diamond prices from key characteristics such as carat, cut, color, clarity, depth, table, length, width, and height. The analysis explores how these features relate to price, examines their distributions and relationships, and applies data preprocessing and feature engineering before model development. Several regression approaches are evaluated, including XGBoost, with Optuna used to tune the XGBoost model. The project combines exploratory analysis, statistical testing, multivariate analysis, and predictive modelling to understand the factors associated with diamond pricing and build an accurate price prediction model.

The project covers the end-to-end machine learning lifecycle:

  • Data Cleaning & EDA:Cleaning invalid measurements, analysing distributions and outliers, and exploring relationships between features and price.
  • Feature Engineering & Preprocessing: Transforming numerical features, encoding categorical variables, and preparing the data for modelling.
  • Model Training & Tuning: Training and comparing regression models, with Optuna used to optimise the XGBoost model..
  • Performance Evaluation: Evaluating model performance using metrics such as RMSE, MAE, and R² on held-out data..
